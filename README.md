## Requirements

- Python 3.13.2
- Git

## How to run the project

```bash
git clone https://github.com/SantiagoSuarezL/a_star_visual.git
cd a_star_visual
python -m venv venv
source venv/bin/activate # or .\venv\Scripts\activate on Windows
pip install -r requirements.txt
python a_star_visual.py
```

## How do you use it?

- Left-click to set the starting point, then the ending point, and then add obstacles.

- Press the spacebar to have A* calculate the best route.

- Press C to clear the map.
